Chép file nhạc / kinh / giảng pháp của bạn vào thư mục này (mp3, m4a, wav, ogg, flac...).
Được phép để trong thư mục con. Game TỰ NHẬN tất cả khi mở màn hình phát (cần chạy qua start.bat).

Không muốn chép? Chạy lien-ket-thu-muc-nhac.bat (chuột phải > Run as administrator)
để liên kết thẳng thư mục F:\I.Kinh,DanThien vào đây.

Loại bài được đoán theo tên file/thư mục:
  "kinh", "chú", "đại bi", "dược sư", "bát nhã", "tụng"  -> Kinh
  "niệm phật", "a di đà", "nam mô"                      -> Niệm Phật
  "giảng", "pháp thoại"                                 -> Giảng pháp
  "vu lan", "báo hiếu", "cha mẹ"                        -> Vu Lan
  còn lại ("đàn", "thiền", "không lời"...)              -> Nhạc thiền

Chỉ dùng file bạn tự thu hoặc được phép sử dụng. TikTok có thể tắt tiếng
hoặc gỡ phiên live nếu phát nhạc có bản quyền của người khác.
