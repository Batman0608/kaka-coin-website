CHÙA BÌNH AN - MÁY CHỦ TẠI NHÀ · ĐỌC TRƯỚC
================================================

1) Giải nén thư mục này vào nơi cố định, ví dụ C:\ChuaBinhAn

2) Mở "cau-hinh-may-chu.bat" bằng Notepad, sửa UPLOAD_MBPS = tốc độ Upload
   đo ở https://www.speedtest.net, rồi lưu lại.

3) Nhấp CHUỘT PHẢI vào "CAI_DAT_MAY_CHU.bat" và chọn "Run as administrator".
   - Tự cài Node.js nếu thiếu (lần đầu cài xong thì chạy lại file này một lần nữa)
   - Mở tường lửa, tắt chế độ ngủ khi cắm điện
   - Máy chủ tự chạy ngầm mỗi khi bật máy
   Xong thì mở: http://localhost:8080/game.html   (chơi)
                http://localhost:8080/server      (tình trạng máy chủ)

4) Nối tên miền dichua.id.vn: làm theo HUONG_DAN_TEN_MIEN.md
   (thêm tên miền vào Cloudflare, đổi nameserver ở Mắt Bão, tạo Tunnel lấy TOKEN),
   rồi nhấp chuột phải vào "KET_NOI_TEN_MIEN.bat" và chọn "Run as administrator".
   Mọi người vào chơi tại: https://dichua.id.vn

5) CẬP NHẬT TỰ ĐỘNG (dễ nhất — khuyên dùng):
   - Nhấp CHUỘT PHẢI vào "TU_CAP_NHAT.bat", chọn "Run as administrator".
   - Máy TỰ tải bản mới nhất từ GitHub, nén mã, chạy thử ở cổng 8081.
     Xem thử ở http://localhost:8081/game.html rồi:
       Y = đưa lên chính thức (tự sao lưu bản cũ)   N = huy
   - Khong can keo-tha file zip. Lan sau co ban moi chi can bam lai file nay.

5b) CẬP NHẬT BẰNG FILE ZIP (nếu không có mạng tới GitHub):
   - Tải file zip bản mới về.
   - Nhấp chuột phải vào "CAP_NHAT.bat" (trong thư mục đang chạy), chọn
     "Run as administrator", rồi kéo-thả file zip bản mới vào cửa sổ và bấm Enter.
   - Bản mới chạy thử ở http://localhost:8081/game.html (bản chính thức vẫn
     chạy bình thường ở 8080 / dichua.id.vn). Kiểm tra xong:
       Y = đưa lên chính thức (bản cũ được sao lưu tự động)
       N = hủy, giữ nguyên bản cũ
   - Có lỗi sau khi cập nhật: chạy "QUAY_LAI_BAN_CU.bat" để trở về bản trước.
   - Thông tin riêng (tài khoản ngân hàng…) điền vào js\cau-hinh-rieng.js:
     file này không bao giờ bị ghi đè khi cập nhật.

CÁC FILE KHÁC
  chay-may-chu.bat      chạy máy chủ có cửa sổ (xem trực tiếp)
  dung-may-chu.bat      tắt máy chủ
  server\nhat-ky.txt    nhật ký khi máy chủ chạy ngầm
  server\thu-tai.js     thử tải: node thu-tai.js 300
  js\shop-config.js     tài khoản ngân hàng, Firebase, địa chỉ máy chủ
  HUONG_DAN_MAY_CHU.md  sức chứa: mỗi kênh 30 người, mỗi người ~0,04 Mbps upload
  HUONG_DAN_NAP_TIEN.md nạp hoa sen, hòm công đức, tài khoản (Firebase)

Mở file .md bằng Notepad hoặc VS Code.
